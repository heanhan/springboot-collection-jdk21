Java 设置 needHr、needDirector 等 Boolean 变量，BPMN 网关用表达式选择 sequenceFlow。

DATA MODEL

业务表与引擎表各司其职

表 / 对象由谁维护学习重点
leave_request业务代码申请人、请假内容、当前业务状态
leave_record业务代码中文审批轨迹，适合直接查询
leave_balance业务代码年假余额，最终同意时扣减
sys_user_roleRBAC 关系通过 user_id / role_code 联表查询角色
sys_role_permissionRBAC 关系通过 role_code / permission_code 联表查询权限
sys_refresh_token双 Token只保存 Refresh Token 的 SHA-256 哈希
ACT_RE_PROCDEFActive7流程定义与版本
ACT_RU_TASKActive7当前未完成任务、候选人、签收人
ACT_HI_TASKINSTActive7历史任务，full history 保留完整轨迹
PRACTICE

五组新手练习

  1. 短假跳过分支：张三提交 1 天年假，确认 HR 与总监没有任务，员工确认后余额变为 9 天。
  2. 长假全链路：提交 5 天年假，依次用王五、赵六、孙七、张三办理。
  3. 退回重填：经理退回，张三改成 2 天事假，重新提交后观察变量和节点变化。
  4. 验证权限：在李四账号尝试查看王五的任务 ID，应得到 403。
  5. 观察数据库：使用 MySQL 客户端连接 springboot_active7 数据库，比较任务办理前后的 ACT_RU_TASK 和 ACT_HI_TASKINST。
