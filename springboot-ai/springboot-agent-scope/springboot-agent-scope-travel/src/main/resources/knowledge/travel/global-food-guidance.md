# 通用旅行饮食指南

## 饮食节奏与预算

保持规律三餐，按时吃饭，避免为了赶行程长时间空腹或暴饮暴食。餐饮预算可以按基础餐、特色餐和饮水零食分别估算。热门店铺的排队和等位时间应计入行程，价格与营业时间需在就餐前实时核实。

## 食品卫生与热量

选择卫生条件稳定、食材充分加热的餐饮场所。生食、凉拌、海鲜和乳制品需要结合保存条件与个人肠胃情况谨慎选择。天气炎热时缩短易腐食品的携带时间，出现异味或保存不当应停止食用。

## 过敏原与特殊饮食

对花生、坚果、乳制品、麸质、海鲜等过敏时，提前准备书面说明并主动询问配料和交叉接触风险。素食、清真或宗教饮食需求应确认餐厅是否具备相应条件，不能只依据菜品名称判断。

## 饮水肠胃与就医

旅行期间适量饮水，避免突然改变饮食结构。出现持续呕吐、腹泻、发热或脱水症状时应停止尝试新食物，及时补充水分并寻求正规医疗帮助。保留就诊记录和保险资料，按医生建议用药。
