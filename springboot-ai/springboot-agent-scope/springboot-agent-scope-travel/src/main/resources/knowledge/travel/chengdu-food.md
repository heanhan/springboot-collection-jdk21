# 成都美食指南

## 美食类型

成都美食以麻辣、鲜香和多样的小吃文化为代表。常见类型包括火锅、串串、川菜、担担面、钟水饺、龙抄手、甜水面和各种街边小吃。第一次尝试重口味食物时，应结合个人肠胃情况选择辣度。

## 用餐区域

选择美食区域时优先考虑住宿和当天行程的顺路程度。市中心商圈、传统街区和交通枢纽附近通常选择较多，但热门店铺可能需要排队。具体店铺是否营业、人均价格和排队情况需要实时查询。

## 点餐建议

多人用餐可以先点少量菜品，根据口味继续加菜。火锅和串串注意食材是否充分加热，路边小吃尽量选择客流量稳定、卫生条件较好的店铺。对花生、芝麻等食材过敏的人需要提前确认配料。

## 饮食提醒

旅行期间保持规律饮食和饮水，不要长时间只吃辛辣食物。出现肠胃不适时应停止尝试新食物，必要时就医。餐厅推荐仅代表一般性方向，不代表对某家店铺实时经营情况的确认。
