# 通用交通与住宿选择

## 城际交通比较

比较飞机、火车、长途汽车等方式时，不只看票价，还要计算机场或车站往返、行李、选座、接驳和时间成本。核对退改签规则、儿童票条件和最晚到达时间。高峰时段应预留更充分的换乘缓冲。

## 市内交通规划

根据当天活动区域组合步行、公共交通、出租车或租车。公共交通需要核对首末班车、换乘和支付方式；租车需要确认驾照、保险、停车、通行限制和还车要求。夜间或携带行李时优先选择安全、可追踪的交通方式。

## 住宿位置与总成本

住宿总成本包括房价、税费、清洁费、押金、早餐、取消政策和往返交通。位置较偏但交通便利的住宿可能比核心区域更划算。预订前核对床型、入住人数、儿童政策和实际评价，不只看宣传图片。

## 入住安全与契约核对

入住时检查门锁、消防通道、卫生条件和贵重物品保管方式。保留预订确认、付款记录和酒店联系方式。遇到临时加价、房型不符或安全隐患时，先与前台核实，必要时联系预订平台或当地正规投诉渠道。
