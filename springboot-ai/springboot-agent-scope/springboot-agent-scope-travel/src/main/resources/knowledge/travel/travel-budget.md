# 旅行预算估算方法

## 预算结构

旅行预算通常包括城际交通、住宿、餐饮、市内交通、门票、购物和弹性费用。先确定总预算和优先级，再按项目分配。预算应写明人数、日期、交通方式、住宿档次等假设，不能把估算值当作实时报价。

## 城际交通预算

比较往返机票、火车票和长途汽车时，同时计入行李、选座、接送和换乘成本。节假日、周末和临近出发日期的价格可能变化。退改签费用也应纳入比较，优先选择总成本与出行需求更匹配的方案。

## 住宿预算

住宿费用不只有房价，还可能包含税费、清洁费、押金和取消成本。多人同行时比较房间数与床位组合，位置较偏的住宿要计入额外交通时间和费用。预订前核对入住人数、床型和儿童政策。

## 餐饮门票与体验

餐饮可以按每日基础餐饮、特色餐和饮水零食估算。门票先列出必去项目，再核对官方票价、预约规则和优惠政策。体验项目、导游、演出和购物应单独列项，避免与必需支出混在一起。

## 弹性费用与价格核实

建议预留总预算的百分之十到二十作为弹性费用，用于天气变化、临时交通、医疗或行程调整。所有价格都应在出行前通过官方渠道重新核实。预算紧张时优先削减可选购物和高成本体验，不要压缩安全与基本休息费用。
