# 旅行预算估算方法

## 预算结构

旅行预算通常包括大交通、住宿、餐饮、市内交通、门票、购物和弹性费用。先确定总预算，再按项目分配，不要把全部预算都用于住宿或门票。不同城市、季节和旅行方式的价格差异较大。

## 交通预算

大交通需要比较往返机票、火车票和行李费用。市内交通可以根据行程区域估算，跨区域景点应单独计算往返成本。节假日和周末价格可能明显变化，应以实际查询结果为准。

## 住宿预算

住宿预算需要结合人数、房间数、位置和卫生条件。两人同行时可以比较一间双床房与两间房的成本。位置较偏的酒店虽然价格低，但可能增加交通时间和费用。

## 餐饮与门票

餐饮可以按“每日基础餐饮 + 特色餐”估算。门票先列出必去景点，再查看官方票价、预约规则和优惠政策。不要假设所有景点都需要购买全价票。

## 弹性费用

建议预留总预算的百分之十到二十作为弹性费用，用于天气变化、临时交通、医疗或行程调整。预算表中应写明假设条件，避免把估算价格表述为实时价格。
