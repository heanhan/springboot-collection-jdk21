# 通用行程规划原则

## 明确目标与约束

先确认旅行目标、日期、人数、预算、体力水平和必须完成的事项，再安排具体活动。亲子、长辈、无障碍或短期商务旅行需要不同的节奏与设施条件。信息不足时先澄清，不要默认某个城市或某种旅行方式。

## 控制节奏与负荷

每天设置一个主要目标和少量可选活动，避免把多个远距离区域塞进同一天。游览、用餐、交通和休息都要占用时间，连续高强度活动后应安排恢复时段。遇到排队、延误或天气变化时，优先删除可选项目。

## 按地理区域组织

把位置相近的景点、餐厅和住宿安排在同一时段，跨区域移动单独计算时间与费用。地图上的直线距离不等于实际通行时间，山区、岛屿、景区接驳和换乘会增加额外成本。具体路线应以目的地官方交通信息为准。

## 首尾日与备选方案

抵达日和返程日减少固定预约项目，为值机、取行李、进城和安检预留缓冲。每日准备一个室内或就近的备选方案，并提前确认取消、改签和预约规则。临时信息变化时，以官方渠道的最新通知为准。
