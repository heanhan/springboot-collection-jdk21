# 成都三天两夜行程

## 行程原则

三天两夜适合围绕市中心与少量代表性景点安排，不建议每天跨多个远距离区域。第一天和最后一天应预留交通时间，第二天可以安排相对完整的游览日。具体开放时间、预约规则和票价需要出行前通过官方渠道核实。

## 第一天：城市与街区

上午抵达后先办理住宿或寄存行李，随后在市中心散步，熟悉城市节奏。下午选择一处历史街区或城市公园，晚上安排轻松的本地餐饮。第一天不要安排过多景点，为高原适应和交通延误预留时间。

## 第二天：代表景点

选择一到两个地理位置相近的代表景点，提前查看官方预约要求。上午游览主要景点，下午根据体力安排博物馆、公园或街区。若前往周边景点，需要单独计算往返交通时间，不建议与市区行程混排过满。

## 第三天：周边与返程

第三天优先选择交通便利的周边区域或市区补漏景点。下午返回取行李并预留前往机场、火车站的时间。若返程时间较早，应取消远距离周边行程。

## 交通建议

市内优先使用地铁、公交和步行结合的方式。跨区域出行前查看地图和实时交通信息。机场、火车站与酒店之间的路线需要根据实际位置确认，不要只依据景点名称判断距离。
